# AI Travel Analyst

## Project Overview

AI Travel Analyst is a data-driven flight price analysis project developed as part of the MIC AIML Department Recruitment Challenge.

The project analyzes flight pricing data to identify patterns and factors associated with flight prices and provides data-driven recommendations for travelers.

## Problem Statement

Flight prices can vary significantly depending on several factors such as airline, travel class, booking time, number of stops, and season.

The goal of this project is to analyze a flight pricing dataset, identify important price-related patterns through exploratory data analysis, and provide useful insights for travelers.

## Dataset Used

The project uses the flight pricing dataset provided by the MIC AIML Department Recruitment Challenge.

The dataset contains information related to airlines, routes, departure details, flight duration, stops, distance, travel class, booking timing, season, booking channel, passenger count, and price.

The original dataset is kept unchanged. A cleaned version is generated by the Python notebook after preprocessing.

## Methodology

The project follows these main steps:

1. Load and inspect the dataset.
2. Identify missing values and duplicate records.
3. Clean inconsistent values in duration and number of stops.
4. Convert numerical columns into appropriate numeric formats.
5. Remove duplicate records.
6. Remove records where the target price is missing.
7. Handle remaining missing numerical and categorical values.
8. Analyze flight price statistics.
9. Create six visualizations to investigate price-related factors.
10. Identify major patterns and provide recommendations.

## Visualizations

The project includes six visualizations:

1. Average Flight Price by Airline
2. Average Flight Price by Travel Class
3. Average Flight Price by Booking Window
4. Average Flight Price by Number of Stops
5. Average Flight Price by Season
6. Average Flight Price by Booking Channel

## Key Results

The analysis identified several important patterns:

* Travel class has a strong association with flight price, with higher classes having substantially higher average prices.
* Flights booked closer to departure have higher average prices in this dataset.
* Flights booked 90+ days in advance have a lower average price than flights booked within 7 days.
* Average price increases with the number of stops in the analyzed dataset.
* Average prices vary across airlines and seasons.
* Booking channel shows comparatively smaller differences in average price.

## Recommendations

Based on the analysis:

* Consider booking flights well in advance rather than waiting until the final week.
* Compare prices across different travel classes and airlines.
* Travelers with flexible schedules can compare prices across seasons.
* Compare multiple flight options based on stops, airline, and other factors rather than relying on one variable.
* Compare booking channels when purchasing a flight, although booking channel showed a weaker association with price in this dataset.

* Missing values across multiple columns.
* Duplicate records.
* Numerical values stored as text.

These inconsistencies were handled during the data preprocessing stage.
